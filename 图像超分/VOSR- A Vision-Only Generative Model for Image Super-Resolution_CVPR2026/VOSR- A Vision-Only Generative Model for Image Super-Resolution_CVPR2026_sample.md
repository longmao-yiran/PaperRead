# VOSR: A Vision-Only Generative Model for Image Super-Resolution - 简要总结

## 核心创新点是什么？

VOSR 是不依赖文生图预训练的生成式图像超分框架。它将 LR 图像的 VAE 结构潜变量与 DINO 视觉语义特征结合，并以“保留弱 LR 结构、移除语义”的部分条件分支取代标准 CFG 的完全无条件分支，使指导系数可在生成自由度和输入忠实度之间调节；随后将多步模型蒸馏为一步模型。

## 主要实验结论或研究结论是什么？

在 LSDIR、RealSR 与 ScreenSR 上，VOSR 显著优于先前纯视觉生成式超分，并在多项感知指标上达到或超过代表性 T2I-SR 方法；其视觉结果对细小文字、桥索等局部结构更忠实。核心扩散训练成本约为代表性 T2I 方法的十分之一，一步版本在 A100 上生成 512×512 图像约需 0.1 秒，表明高质量生成式超分不必依赖多模态预训练。
