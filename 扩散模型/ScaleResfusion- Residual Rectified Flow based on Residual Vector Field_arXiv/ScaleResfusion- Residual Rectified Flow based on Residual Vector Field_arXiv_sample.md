# 核心创新点是什么

将低质与高清图像的加权残差加入预训练 Rectified Flow 的线性路径和速度目标，推导出仅由低质输入与高斯噪声构造的精确加速起点；冻结大模型主干，以 LoRA 适配残差速度场，并用 DMD 正则少步恢复结果。

# 主要实验结论或研究结论是什么

默认 FLUX.2-Klein 4B 模型用 4 次网络评估，在 DRealSR 上无 GAN 版本达到 29.77 dB PSNR、118.18 FID。消融显示残差初始化、低质特征条件及分布正则均有贡献；方法可迁移到 SD3、FLUX.2 和 Z-Image 主干。图像残差较局部、低能量的观察不构成 LoRA 参数低秩的证明。
